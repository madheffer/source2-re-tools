# source2-re-tools

The reverse-engineering tooling behind the Source 2 resource compiler (rc-standalone) and
cs2-map-compiler: one copy both repos use, split out of the compiler with its history on 2026-11-15.

| Path | What |
|---|---|
| `tools/re/` | Ghidra / ReVa helpers, Frida capture scripts, oracles (tier0 KV3, exp2f, shader dictionaries), `make_manual.py`, the per-build name tables in `tools/re/names/` |
| `tools/ghidra_scripts/` | Ghidra scripts |
| `docs/ADDRESSES.md` | Addresses per DLL build, generated by `tools/re/make_manual.py` |

Addresses are recorded here per DLL build, never in notes or memory. After every CS2 update run
`tools/re/patch_check.py`, then `tools/re/build_diff.py`.

The compiler repos still carry a copy of `tools/re` while their oracle tests call those scripts by path;
new RE work goes here.
